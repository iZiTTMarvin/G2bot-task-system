# G2 工作台界面

本轮由用户授权替换 UI 架构。保留真实后端、任务状态、不可变版本、核验与交付门禁；不改变模型配置、不迁移业务数据。

## 任务与结构

- 主任务：描述采集目标，生成任务，逐条修改核验，导出可交付版本。
- 左侧为任务集导航，生成和审核入口保留明确区分；新任务集不在页面加载时自动创建。
- 主区采用 AI Elements Conversation、Message、PromptInput；消息可读宽度限制，跟随滚动尊重用户阅读位置。
- 宽窗口右侧保留执行与结果面板，运行时展示真实事件、已用时间和停止入口；窄窗口用对话/执行与结果切换，移动端导航收进 Sheet。
- 任务审核在宽 Sheet 内完成，正文与核验有独立层级。核验勾选加共用说明可映射为逐项证据，不代替用户自动确认。

## 系统与视觉

仅使用 shadcn/ui + AI Elements，替换 Ant Design。Tailwind v4、Radix 处理语义、焦点、键盘与浮层；lucide 为唯一图标来源。来源为官方 registry，组件代码归项目维护。

使用中性灰、墨色主操作与 G2 蓝色识别标记。颜色主要表达状态，不用大面积告警卡片重复同一错误。正文 14px，次级文字不低于 12px；步骤与物料优先于解释文案。支持浅色/深色/系统主题与减少动态效果偏好。

## 状态归属

| 状态 | 唯一来源 |
|---|---|
| 任务、版本、审核、执行进度 | 后端 API |
| 会话当前资料 | 会话引用和批次快照 |
| 输入草稿与附件选择 | 页面内按会话索引的草稿 |
| 当前任务编辑、核验选择 | 任务详情表单，仅保存/确认时提交 |
| 主题 | next-themes 的 g2-theme 设置 |

初始化、加载、空、失败、部分结果、后台作业、保存失败、乐观锁冲突均有明确反馈。仅在完整失败时提供原请求重试；部分审核失败保留成功结果并提示逐条重审。停止请求由后端确认，等待当前模型调用结束期间保持运行占用；它不是可恢复的暂停。

## 验证

覆盖 390×844、768×1024、1440×1000 与宽屏；正常/空/失败/长内容、键盘与弹窗、深色主题。端到端使用独立临时库和演示模型；真实模型质量与机器人现场能力不属于 UI 验收。
