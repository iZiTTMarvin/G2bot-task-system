# G2 任务系统文档入口

当前实施目标：本地 Demo，一个任务生成 Agent、一个任务审核 Agent、一个人工审核模块。后端 Python，前端 React + Vite。

按以下顺序阅读：

1. [Demo 项目蓝图](./Demo项目蓝图.md)：范围、架构、页面、状态与验收。
2. [前后端接口契约](./前后端接口契约.md)：接口语义、数据类型、错误及联调规则。
3. [OpenAPI 契约](./openapi.json)：机器可读的请求、响应和字段定义；前端 mock 与后端实现的共同依据。
4. [双人实施清单](./双人实施清单.md)：Owner、先后顺序、并行边界与验收记录。

这组文档是 2026-10-28 讨论后形成的 Demo 开发基线；方案与接口尚未实现、尚未经真实模型及浏览器验收。字段与 HTTP 结构以 `openapi.json` 为准，业务规则以接口契约为准，范围以项目蓝图为准。发现冲突先同步修正文档，不让两端分别猜测。

[原产品与架构设计](./G2任务系统-产品与架构设计.md) 保留为完整产品讨论资料；其中经理、多生成员、Swarm、双审核和规则自动化流程不属于今晚 Demo。原文中的“已收敛到可开工”和固定数量不作为当前实施依据。

文档变更由后端负责人维护接口基线，前端负责人核对页面与调用影响；已开始联调后，破坏性字段或语义变更必须双方同步。
