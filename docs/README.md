3. [Deep Agents 实现说明](./DeepAgents实现.md)：Provider、执行证据和只读 Skill 运行方式。
4. [UI 架构重构验收](./UI架构重构验收.md)：shadcn/ui 与 AI Elements、交互检查、截图及未验证范围。
