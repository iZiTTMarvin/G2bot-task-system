# G2 能力判断（拿不准时读取；末端限制与场景约束每次出题都要遵守）

## 设备画像

- 采集机器：G2；机械臂：珞石臂；末端：90D 平行两指夹爪（V235 版本）。
- **作业期间底盘不动、腰部不动**，只设计双臂可触及的桌面范围内的动作。
- 末端是**两根平行手指，只能整体张开、闭合**：能夹、捏、托、推、拨、按（用合拢的指尖下压）、拉（拉链头、拉环、抽屉把手）。没有可单独弯曲的手指，也没有大的握力。

## 夹爪做不了的工具与动作（出题前逐项排除）

| 类型 | 例子 | 原因 |
|---|---|---|
| 握住同时还要扣动 | 扫码枪、喷壶扳机、胶枪、价签枪、电钻 | 握住工具后没有第二根手指去扣扳机 |
| 需要大力压下或握合 | 订书机、打孔器、压蒜器、核桃夹、长尾夹（大号） | 指尖下压和闭合的力不够 |
| 需要两指交叉张合 | 剪刀、镊子精细夹取 | 平行夹爪不能做剪切和精细对夹 |
| 精细薄软 | 撕单张纸或背胶纸、把书壳塞进透明书皮插袋、穿针、系鞋带、扣纽扣 | 夹不住薄边或对位要求太高 |
| 用笔书写 | 写字、试写、签名、写标签或复杂绘图 | 不按稳定书写设计；用户允许有真实标记目的时画一横，可拔插适合抓取的笔帽。握持、阻力和画线须用实物核验（L-024） |
| 小而光滑 | 小于 1cm 的零件、纽扣电池、扁平卡片贴桌面时 | 夹爪抓不起来 |
| 杆身过长或体积过大 | 拖把、小扫把、帐篷、行李箱等 | 双手在桌面范围内没法握持这么长的杆，超大件还要动底盘或弯腰 |

可以用的“工具”：单手握持就能完成的（勺子、梳子、抹布、刷子、食物夹、按压式喷头、大号塑料夹子、笔）。

## 常见可用动作

### 当前工位姿态限制（L-029，优先于通用动作和旧范例）

- 不安排夹持整件物品倒置、翻底、翻到背面或大幅扭腕，不靠持续绕圈手摇拉长时长。用户于2026-10-24结合现场照片明确指出该限制。
- 箱底留在桌面上时抬起铰链侧板，与把整箱翻底不同；仍须核验实际抓取位置、可达范围和卡扣阻力。不能通过采集员预翻零件来规避禁令。
- 竖直低阻力拧盖、小角度倾斜和拉链取用均不能仅凭照片判为可做；缺少实物证据时标为待核验。照片只支持末端外形观察，不能给出关节角、扭矩、负载或成功率。
- 需要倒置、连续绕圈、窄孔对位或大力卡合的任务，先撤下或重选；不能删除核心作业后仍声称完成原目标。

夹取、取放、开合盒盖、抽屉推拉、扶物拧大盖、拉拉链、对折线缆、铺展折叠布料、撑开袋口、套袋、干擦、端轻型托盘、翻书页、插入固定容器（插花、插笔筒）、拔插笔帽、按压扣合盒盖/按扣、干料倾倒（茶叶/豆子/坚果从袋倒进罐）、密闭容器内的拉动机构（手动打碎机拉环）。

## 默认不能

办公供电准备可包括把原有匹配电源插到电脑和断电插排上，不扩展为带电插拔、通电测试或处理裸露导体。接头可抓握、插口可达和插入力须用实物核验；不因包含电源就删除合理的供电准备，也不因写了“插入”就视为已验证成功。

移动底盘或腰部、伸手到不可达地面、开冰箱门、真实倒水倒液体/湿洗、碎屑散落桌面/抛洒粉末、加热做饭、扣传统纽扣、系鞋带、穿针、抓极小光滑零件、处理重物、危险刀具或带电高风险操作，以及上表所有工具；杆身过长、握不到或超出双臂桌面可达范围的大件（拖把、小扫把、帐篷这类）同样不出题（L-004）。

## 场景与物品约束（来自现场采集规范，出题时必须满足）

- 桌面基底为纯白或原木色，可铺不同样式桌布；背景是桌面、沙发、茶几、书架等实景。货架、灶台、水槽等不在清单里的环境，未经确认不出题。
- **单条数据场景物品 2～10 件，平均 4～5 件为宜；单个任务涉及的物品总数不超过 20 件。**
- **操作物不能和桌面或桌布同色**：白桌面上避开白色、透明物品（透明书皮、白纸巾、白绷带），需要时注明铺深色桌布。
- 物品符合场景调性和日常生活，摆放疏密适中，不堆砌杂物。
- 动作要符合人的日常习惯：单手能完成的不写成双手传递，不设计需要等待的步骤（单条数据停顿不能超过 3 秒），整条任务按正常节奏能在 10 分钟内完成。
- 采集结束时的手臂复位由采集员录制，**不写进任务步骤**。

## 不属于任务设计的规范

VR 佩戴、投影校准、设备核查、常规/非常规数据标签、错误恢复次数、线束整理、灯光调试，这些是采集员和运维的要求，不写进任务。

## 判定时问

①平行两指能否抓牢或捏住？②是否需要扣扳机、大力按压或剪切？③双臂有操作空间并能退出？④需要扶稳的动作（拧盖、拉拉环）采集员能否自然完成？步骤里不写用几只手。⑤物品是否会滑动、滚落、破碎，颜色是否与桌面区分得开？⑥场景物品数是否在 2～10 件，五套能否配齐？⑦每条数据能否低成本快速复位？

开合拉链、套枕套、处理软袋与易变形材料依赖物品尺寸和抓取条件：文本可列为候选，**没有实物和工位证据时不能保证实操通过**。
