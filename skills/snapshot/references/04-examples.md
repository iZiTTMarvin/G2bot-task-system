# 范例（学习组织方式，不照搬场景）

长任务模板是设计示意，未声称已经过审核或现场验证。标明为历史案例的内容经过措辞整理，名称按当前规范改写；仅供理解组织方法，不代表符合当前全部规则或现场时长。

## 长任务模板

生成或重写长任务、复合任务前读本节；它提供组织方法，不要求复制场景、步数、清洁开头或统一收尾。步数与判重规则以 `../SKILL.md` 为准。下方历史案例仅作写法参考，动作仍须符合当前平台规则。

### 从优秀案例提炼的组织方法

先写一句内部设计依据：**初态是什么 → 谁为了什么做这件事 → 最后留下什么状态**。再列相关子工作，按物理依赖展开取物、操作、放置；每件物品应能解释其用途。相邻子工作可以独立完成，只要共同服务这一件真实工作。

例如整理并标记书本时，若现场有合适的笔、笔帽和印章，可补入取书、拔帽、画一横、盖帽与盖章等服务同一目的的动作；收存时再放回工具。不为延长任务加入无关物品或重复开合。笔帽抓取、画线和实际物料须现场核验；不扩展为写字或签名。

擦拭或刷拭不是默认准备步骤：只有任务确有脏污、灰尘或残留要清除，且交付内容写明脏污和位置时才采用。不要自行编造脏污，更不要为凑步加入清洁。

| 人工优秀案例 | 相关子工作的组织方式 | 完成状态 |
|---|---|---|
| 备好茶点待客盘 | 准备承载面→分装点心糖果→配餐巾牙签与杯具 | 客人可直接取用 |
| 摆好办公工位 | 摆设备→连接外设与电源→配办公用品→移开空包 | 桌面可开始办公 |
| 整理户外用品货架 | 整理货架→设置价签→按物品用途堆叠、折叠或挂放 | 商品可展示取用 |
| 打包双杯外卖饮品 | 准备袋与杯托→放饮品→配吸管纸巾小票→完成包装 | 整单待取 |

以上提炼自用户提供的优秀案例；学习关联与顺序，不把其中倒水、提手修整等动作直接当作平台可行性证据。物料写 `【水果1】【水果2】`、`【点心1】【点心2】` 等可替换类别，保留动作所需结构（如盖子可取下、杯托适配）；不能只换名称却仍要求某一品种或型号。

### 正向与反向各自成立

- **准备办公**：电脑、外设和资料在包内→准备开始办公→设备展开连接、用品留在取用位置、空包移开。
- **下班收存**：办公已结束且设备仍连接→整理携带离开→断开连接、整理线缆、合上电脑、装包并拉好拉链。按收存依赖重写步骤；与正向任务可以使用同套物料。
- **不成立**：新泡好的茶没有处理原因就倒掉再重泡；或已装好的包又掏空再装回。判重与反向复核见 `03-diversity.md`。

### 步骤粒度示例

```txt
1.打开【回收盒】的盒盖
2.把【回收盒】的盒盖放到桌面上
3.从桌面拿起【回收物1】
4.把【回收物1】放进【回收盒】
```

这是局部粒度示例，不是一条完整长任务。每步写可独立执行的动作；不把伸手、靠近、观察拆成步骤。必要的两件作业分别展开，不为延长任务反复取放同一物品。

### 完整示例：盖章整理书本（39 步）

初态：两本书需做标记后整理，书在书架上；可抓握的带帽笔、印章和印泥盒在文具盒内。终态：书本完成标记并叠放，使用过的文具收好。此例展示关联物品和衍生动作，笔帽尺寸与阻力、夹持画横及盖印仍须现场验证；不以步数推断时长。

任务名字：`嘉兴数采-盖章整理书本`

```txt
1.打开桌面上【文具盒】的盒盖
2.从【文具盒】里拿出【笔】
3.将【笔】放到桌面右侧
4.从【文具盒】里拿出【印章】
5.将【印章】放到桌面右侧
6.从【文具盒】里拿出【印泥盒】
7.将【印泥盒】放到桌面右侧
8.从书架上拿起【书本1】
9.将【书本1】放到桌面中央
10.打开【书本1】
11.拿起桌面上的【笔】
12.拔下【笔】上的【笔帽】
13.将【笔帽】放到桌面上
14.用【笔】在【书本1】页面画一横
15.拿起桌面上的【笔帽】
16.将【笔帽】盖回【笔】上
17.将【笔】放到桌面右侧
18.打开【印泥盒】的盒盖
19.拿起桌面上的【印章】
20.用【印章】蘸取【印泥盒】里的印泥
21.用【印章】在【书本1】页面盖章
22.将【印章】放到桌面右侧
23.合上【书本1】
24.将【书本1】放到桌面左侧
25.从书架上拿起【书本2】
26.将【书本2】放到桌面中央
27.打开【书本2】
28.拿起桌面上的【印章】
29.用【印章】蘸取【印泥盒】里的印泥
30.用【印章】在【书本2】页面盖章
31.将【印章】放到桌面右侧
32.合上【书本2】
33.将【书本2】叠放在【书本1】上
34.合上【印泥盒】的盒盖
35.拿起桌面上的【印章】放进【文具盒】里
36.拿起桌面上的【笔】放进【文具盒】里
37.拿起桌面上的【印泥盒】放进【文具盒】里
38.合上【文具盒】的盒盖
39.将【文具盒】放到桌面右后方
```

单套所需物料：文具盒1个、笔1支、印章1个、印泥盒1个、书本2个、笔帽1个。

## 补充茶叶（11 步｜干料倾倒 + 夹子取还 + 盖子闭环）

任务名称：
```txt
补充茶叶
```
固定步骤：
```txt
1.拿起桌面上的【茶叶罐】
2.打开【茶叶罐】的盖子
3.将【茶叶罐】和盖子放到桌面上
4.拿起【收纳盒】里的【茶叶袋】
5.取下【茶叶袋】上的【夹子】
6.将【夹子】放到桌面上
7.撑开【茶叶袋】的袋口
8.将【茶叶袋】里的茶叶倒进【茶叶罐】里
9.拿起桌面上的【夹子】夹住【茶叶袋】袋口
10.将【茶叶袋】放回【收纳盒】里
11.拿起桌面上的盖子盖回【茶叶罐】上
```
要点：目标是一句话就说清的家务；盖子和夹子都“拿下→放桌面→用完还回”；散装茶叶不加【】；步骤内的“和”不受命名规范限制。交付时名称要加基地前缀，如 `嘉兴数采-补充茶叶`。

## 手动拉线打碎饼干（16 步｜同类 2 件 + 盖子开合 + 拉动机构）

任务名称：
```txt
手动拉线打碎饼干
```
固定步骤：
```txt
1.拿起桌面上的【手动打碎机】
2.将【手动打碎机】放到桌面中央
3.拿下【手动打碎机】的盖子
4.将盖子放到桌面上
5.拿起桌面上的【饼干1】
6.将【饼干1】放进【手动打碎机】里
7.拿起桌面上的【饼干2】
8.将【饼干2】放进【手动打碎机】里
9.拿起桌面上的盖子
10.将盖子盖在【手动打碎机】上
11.按住【手动打碎机】机身
12.捏住【手动打碎机】拉绳上的拉环
13.来回拉动【手动打碎机】拉绳上的拉环
14.松开【手动打碎机】拉绳上的拉环
15.拿下【手动打碎机】的盖子
16.将盖子放到桌面上
```
要点：靠“2 块饼干 + 盖子开合”自然达到 16 步；碎屑全在密闭机身内，不散落桌面；原稿“一手扶着/一手捏住”改为“按住/捏住”，不限定手数。

## 打包手提包（16 步｜拉链开合 + 去除填充物 + 袋子准备与扣合）

任务名称：
```txt
打包手提包
```
固定步骤：
```txt
1.拉开【手提包1】的拉链
2.拿出【手提包1】里的【气泡膜1】
3.将【气泡膜1】丢进【垃圾桶】
4.拉上【手提包1】的拉链
5.拉开【手提包2】的拉链
6.拿出【手提包2】里的【气泡膜2】
7.将【气泡膜2】丢进【垃圾桶】
8.拉上【手提包2】的拉链
9.拿起桌面上的【打包袋】
10.将【打包袋】展开
11.打开【打包袋】的袋口
12.撑开【打包袋】的袋口
13.拿起桌面上的【手提包1】放进【打包袋】里
14.拿起桌面上的【手提包2】放进【打包袋】里
15.扣上【打包袋】的按扣
16.将【打包袋】立起来放在桌面上
```
要点：每个包“开拉链→取填充物→关拉链”自成闭环；打包袋有完整的“展开→撑开→装入→扣上”准备与收尾；原稿从【收纳盒】取袋，改为桌面取袋，把容器控制在 2 个以内。

## 历史案例：摆放仿真餐点（20 步｜用户认可）

任务名称：
```txt
嘉兴数采-摆放仿真餐点
```
固定步骤：
```txt
1.拿起桌面上的【托盘】放到桌面中央
2.拿起桌面上的【果盘】放到托盘左侧
3.拿起桌面上的【碗】放到托盘右侧
4.拿下【食物盒】的盒盖
5.将盒盖放到桌面右侧
6.拿起桌面上的【食物夹】
7.用【食物夹】从【食物盒】里夹起【水果1】
8.将【水果1】放进【果盘】中央
9.用【食物夹】从【食物盒】里夹起【水果2】
10.将【水果2】放在【水果1】左侧
11.用【食物夹】从【食物盒】里夹起【水果3】
12.将【水果3】放在【水果1】右侧
13.用【食物夹】从【食物盒】里夹起【蔬菜1】
14.将【蔬菜1】放进【碗】里
15.用【食物夹】从【食物盒】里夹起【蔬菜2】
16.将【蔬菜2】放在【蔬菜1】旁
17.将【食物夹】放到托盘前侧
18.拿起桌面上的盒盖
19.将盒盖盖回【食物盒】上
20.端起桌面上的【托盘】放到桌面前侧
```
要点：物料全是能配齐五套的基础名（L-016）；水果进果盘、蔬菜进碗，摆放符合习惯（L-012）；食物夹真正用于夹取，盒盖有开有合；布置完不撤回，没有往返抵消。

## 历史反例：整理茶几、上架洋酒样瓶

旧案例曾加入擦杯垫、桌面、样品架、酒瓶和台签的步骤，却没有交代各处脏污及清洁原因；这些擦拭不符合当前 L-037，不能照搬。整理与上架可以保留有用途的取放、开合和单件穿插，不为保留原步数补造清洁理由。

## 不采用的通过案例

审核员也通过过“冲泡蜂蜜柠檬水”（拿起【水壶】向【杯子】里倒入温水、用【勺子】舀取适量蜂蜜）。它违反“不碰真水真液体”和“禁用适量”的现场规则，本技能不照此出题。只能说明审核员接受“冲泡/调配”类真实家务目标，可换成干料版本。

## 反例

`1.拿起【托盘】 2.把【托盘】移到桌面中央 3.把【托盘】放回原处`：无有效工作结果。

`1.拿起【食品袋】 2.把【食品袋】反复折叠 3.把【食品袋】放回桌面`：无实际需求的技能展示。

`双臂协同拧开【蜂蜜罐】的盖子`：强制双手，改为 `拧开【蜂蜜罐】的盖子`。

`镜片擦拭折腿后眼镜盒收纳`、`书本擦封夹签后书立推紧`：“XX后XX”和宾语前置都违规，可按共同目标改为 `收纳眼镜`、`整理书本`；实际必要动作仍写在步骤里。

`书本贴签叠放后文具归盒擦桌`（历史任务名称）：宾语前置加“后”，可改为 `嘉兴数采-整理书桌`；原有步骤须按当前手数、动作粒度和能力规则审查。

`布置客房迎宾托盘`、`打包音乐课乐器`：场景不是必要信息时，可改为 `布置迎宾托盘`、`打包儿童打击乐器`；确需区分场景时可写 `在柜台摆放样品`。`把象棋收进棋盒`：“把”字句属于宾语前置，改为 `收纳象棋`。
