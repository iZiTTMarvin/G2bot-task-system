# 范例（据审核员实际通过的任务整理，照写法，不照搬场景）

整理时只统一了措辞：补齐 `1.` 编号、同类物品加编号、补写拿起来源、删去“双臂协同/一手”等指定手数的措辞、去掉多余容器。动作链和步数与通过原稿一致。

## 补充茶叶（11 步｜干料倾倒 + 夹子取还 + 盖子闭环）

任务名称：
```txt
补充茶叶
```
固定步骤：
```txt
1.拿起桌面上的【茶叶罐】
2.打开【茶叶罐】的盖子
3.将【茶叶罐】和盖子放到桌面上
4.拿起【收纳盒】里的【茶叶袋】
5.取下【茶叶袋】上的【夹子】
6.将【夹子】放到桌面上
7.撑开【茶叶袋】的袋口
8.将【茶叶袋】里的茶叶倒进【茶叶罐】里
9.拿起桌面上的【夹子】夹住【茶叶袋】袋口
10.将【茶叶袋】放回【收纳盒】里
11.拿起桌面上的盖子盖回【茶叶罐】上
```
要点：目标是一句话就说清的家务；盖子和夹子都“拿下→放桌面→用完还回”；散装茶叶不加【】；步骤内的“和”不受命名规范限制。交付时名称要加基地前缀，如 `嘉兴数采-补充茶叶`。

## 手动拉线打碎饼干（16 步｜同类 2 件 + 盖子开合 + 拉动机构）

任务名称：
```txt
手动拉线打碎饼干
```
固定步骤：
```txt
1.拿起桌面上的【手动打碎机】
2.将【手动打碎机】放到桌面中央
3.拿下【手动打碎机】的盖子
4.将盖子放到桌面上
5.拿起桌面上的【饼干1】
6.将【饼干1】放进【手动打碎机】里
7.拿起桌面上的【饼干2】
8.将【饼干2】放进【手动打碎机】里
9.拿起桌面上的盖子
10.将盖子盖在【手动打碎机】上
11.按住【手动打碎机】机身
12.捏住【手动打碎机】拉绳上的拉环
13.来回拉动【手动打碎机】拉绳上的拉环
14.松开【手动打碎机】拉绳上的拉环
15.拿下【手动打碎机】的盖子
16.将盖子放到桌面上
```
要点：靠“2 块饼干 + 盖子开合”自然达到 16 步；碎屑全在密闭机身内，不散落桌面；原稿“一手扶着/一手捏住”改为“按住/捏住”，不限定手数。

## 打包手提包（16 步｜拉链开合 + 去除填充物 + 袋子准备与扣合）

任务名称：
```txt
打包手提包
```
固定步骤：
```txt
1.拉开【手提包1】的拉链
2.拿出【手提包1】里的【气泡膜1】
3.将【气泡膜1】丢进【垃圾桶】
4.拉上【手提包1】的拉链
5.拉开【手提包2】的拉链
6.拿出【手提包2】里的【气泡膜2】
7.将【气泡膜2】丢进【垃圾桶】
8.拉上【手提包2】的拉链
9.拿起桌面上的【打包袋】
10.将【打包袋】展开
11.打开【打包袋】的袋口
12.撑开【打包袋】的袋口
13.拿起桌面上的【手提包1】放进【打包袋】里
14.拿起桌面上的【手提包2】放进【打包袋】里
15.扣上【打包袋】的按扣
16.将【打包袋】立起来放在桌面上
```
要点：每个包“开拉链→取填充物→关拉链”自成闭环；打包袋有完整的“展开→撑开→装入→扣上”准备与收尾；原稿从【收纳盒】取袋，改为桌面取袋，把容器控制在 2 个以内。

## 长任务标杆：夹取仿真餐点并摆好托盘（20 步｜用户认可）

任务名称：
```txt
嘉兴数采-夹取仿真餐点并摆好托盘
```
固定步骤：
```txt
1.拿起桌面上的【托盘】放到桌面中央
2.拿起桌面上的【果盘】放到托盘左侧
3.拿起桌面上的【碗】放到托盘右侧
4.拿下【食物盒】的盒盖
5.将盒盖放到桌面右侧
6.拿起桌面上的【食物夹】
7.用【食物夹】从【食物盒】里夹起【水果1】
8.将【水果1】放进【果盘】中央
9.用【食物夹】从【食物盒】里夹起【水果2】
10.将【水果2】放在【水果1】左侧
11.用【食物夹】从【食物盒】里夹起【水果3】
12.将【水果3】放在【水果1】右侧
13.用【食物夹】从【食物盒】里夹起【蔬菜1】
14.将【蔬菜1】放进【碗】里
15.用【食物夹】从【食物盒】里夹起【蔬菜2】
16.将【蔬菜2】放在【蔬菜1】旁
17.将【食物夹】放到托盘前侧
18.拿起桌面上的盒盖
19.将盒盖盖回【食物盒】上
20.端起桌面上的【托盘】放到桌面前侧
```
要点：物料全是能配齐五套的基础名（L-016）；水果进果盘、蔬菜进碗，摆放符合习惯（L-012）；食物夹真正用于夹取，盒盖有开有合；布置完不撤回，没有往返抵消。

## 长任务场景一致：收好茶几杯具并擦净桌面（20 步）

任务名称：
```txt
嘉兴数采-收好茶几杯具并擦净桌面
```
固定步骤：
```txt
1.拿起桌面上的【保温杯】
2.拧紧【保温杯】的杯盖
3.将【保温杯】立放进【收纳篮】左侧
4.从【杯垫】上拿起【杯子】
5.将【杯子】杯口朝下放进【收纳篮】右侧
6.从【纸巾盒】里抽出一张纸巾
7.用纸巾擦拭【杯垫】表面
8.将纸巾丢进【垃圾桶】
9.拿起桌面上的【杯垫】
10.将【杯垫】竖插进【收纳篮】侧边
11.拿起桌面上的【遥控器】
12.将【遥控器】放到【纸巾盒】旁
13.拿起桌面上的【抹布】
14.将【抹布】展开铺平
15.用【抹布】擦拭杯子放过的桌面
16.用【抹布】擦拭保温杯放过的桌面
17.将【抹布】对折
18.将【抹布】放到桌面右侧角落
19.将【纸巾盒】推到桌面左后方
20.将【收纳篮】推到【纸巾盒】旁
```
要点：每种物品只用 1 件，步数靠拧紧、倒扣、擦杯垫、竖插、擦桌面这些真实操作撑起来（L-019）；所有物品都是茶几上本来就有的东西（L-020）。它的前一版先卷毛巾、再收杯具，毛巾与茶几收尾无关，被用户问“毛巾加入有什么意义”后改成这一版。

## 不采用的通过案例

审核员也通过过“冲泡蜂蜜柠檬水”（拿起【水壶】向【杯子】里倒入温水、用【勺子】舀取适量蜂蜜）。它违反“不碰真水真液体”和“禁用适量”的现场规则，本技能不照此出题。只能说明审核员接受“冲泡/调配”类真实家务目标，可换成干料版本。

## 反例

`1.拿起【托盘】 2.把【托盘】移到桌面中央 3.把【托盘】放回原处`：无有效工作结果。

`1.拿起【食品袋】 2.把【食品袋】反复折叠 3.把【食品袋】放回桌面`：无实际需求的技能展示。

`双臂协同拧开【蜂蜜罐】的盖子`：强制双手，改为 `拧开【蜂蜜罐】的盖子`。

`镜片擦拭折腿后眼镜盒收纳`、`书本擦封夹签后书立推紧`：“XX后XX”和宾语前置都违规，改为 `擦拭眼镜并收进眼镜盒`、`夹好书签并推紧书立` 这类动词在前的动宾短语。

`书本贴签叠放后文具归盒擦桌`（审核已通过的步骤，名称被新规打回）：宾语前置加“后”，改为 `嘉兴数采-整理书本文具并擦拭桌面`。该任务步骤里原有的“双手拿起”“双手捧起”“作书签”“再次整理对齐”按手数规则和“不写目的/含糊动作”改掉：`从书桌左侧拿起【笔记本】叠放在【书本】封面上方并对齐边缘`、`将【抹布】再次对折放回书桌右上角`。

`布置客房迎宾托盘`、`打包音乐课乐器`：带场景词，改为 `布置迎宾托盘`、`打包儿童打击乐器`。`把象棋收进棋盒`：“把”字句属于宾语前置，改为 `收起象棋并折叠棋盘`。


## 完整场景跨度：办公准备（2026-10-24用户确认的设计方向）

使用者要把电脑和本次纸质资料准备好，因此电脑、电源、键鼠、资料袋与笔记本有共同用途。子目标可分别完成，不等于拼盘。此例是方向和格式范例，未通过机器人实物验收；供电插接在断电插排上进行。不能改写成特定支架旋钮、键盘支脚或强制分仓来补步数。

```txt
嘉兴数采-备好电脑并接好电源
```

```txt
1.拉开桌面上【电脑包】的拉链
2.撑开【电脑包】的袋口
3.把【笔记本电脑】从【电脑包】放到桌面
4.打开【笔记本电脑】的屏幕
5.把【键盘】从【电脑包】放到电脑前
6.从【电脑包】拿出【鼠标垫】
7.把【鼠标垫】铺在【键盘】旁
8.把【鼠标】从【电脑包】放到【鼠标垫】上
9.把【电源适配器】从【电脑包】放到电脑旁
10.展开【电源适配器】的线缆
11.把充电接头插入【笔记本电脑】
12.把电源插头插入桌面上的【插排】
13.把【资料袋】从【电脑包】放到桌面
14.拉开【资料袋】的拉链
15.撑开【资料袋】的袋口
16.把【资料本】从【资料袋】放到电脑旁
17.翻开【资料本】
18.拉上【资料袋】的拉链
```
