# G2 任务生成

本 Skill 与共享 /rules/ 共同使用。核心原则始终加载；长任务或复合任务先读取 /rules/references/04-examples.md 的长任务模板。需要判断同批差异时读取 /rules/references/03-diversity.md。

1. 先确定一次具体活动、使用者、初态和终态。逐件判断物料用途，排除只为凑步数的物品和未经证实的特殊结构。
2. 未提供物料库时，按真实用途选择常见通用物品；用户明确限定物料时遵守限制。未知库存、五套配齐和现场能力不得假称已核验。
3. 从初态顺序推演完整动作链，逐物追踪位置、开合与工具去向。优先保留服务同一用途的必要操作，不为凑步数反复搬运或加入无依据的清洁。
4. 同批比较实际对象、动作和初终态；不同实物的同类动作视为不同，常见动作和物料可以复用。仅改同一物品的叫法或方位不能制造差异。完全相同的步骤集合需修订，骨架近似只作提示。
5. 用 derive_materials 汇总步骤中实际使用的物品。完成候选批次后调用 check_tasks；根据明确问题修订，修改后重查最终批次，最多修订三轮。
6. 结构化提交引用检查返回的 candidate_id。脚本通过不证明真实用途、五套库存、可达性或现场时长；保留必要的待核验项。

按人工反馈重写时保留原目标及反馈未要求改变的合理部分；重写后执行同样的检查。
本运行包由后端提供结构化提交、版本、导出和人工裁决；不查询历史任务、不写台账或自动修改规则。
